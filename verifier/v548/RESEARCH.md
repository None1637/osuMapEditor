# v548：弱标签相位精修的 20 首泛化验证

## 结论先行

**弱标签确实含有声学相位信息，但本轮精修器没有相对“只做全局偏移”的基线泛化出稳定收益；密集短红线区也仍未解决。**

- 固定 20 首、17,149 个物件上，四种配置的全曲 ±5 ms 弱标签一致率为 63.34%–63.42%，全局偏移基线为 63.05%。表面最高只增加 64/17,149，且主要来自全局校准异常的 `sample-027`。
- 排除 3 首校准异常后，17 首的 top2 / 短程 DP 为 **10,487/16,140（64.98%）**，基线为 **10,499/16,140（65.05%）**，反而少 12 个；逐歌曲相对基线的中位变化为 **−0.17 个百分点**，7 首改善、2 首持平、10 首变差。
- 密集区只有 7 首、254 个物件。top2 / 短程 DP 为 **125/254（49.21%）**，基线为 **124/254（48.82%）**；max / 短程 DP 为 126/254。逐歌曲相对基线的中位变化分别为 **−5.88** 和 **−2.94 个百分点**，都是 2 首改善、1 首持平、4 首变差。
- 事先选出的 5 首“含至少 2 条密集短红线”的变速样本中，密集区只有 247 个物件：max / 短程 DP 与基线同为 **120/247**，top2 / 短程 DP 为 **119/247**。微合计没有可靠提升。
- 因此，本轮**不把精修器接入生产检测器，也不宣称达到每个音 offset 误差低于 5 ms**。当前数字仍是已知谱面红线、已知物件时间下的弱标签一致性，不是独立声学 onset 精度，更不是全自动 BPM/变速发现正确率。

本轮没有修改生产 BPM 代码。

## 1. 固定样本与防事后挑选

选样在查看精修结果之前完成，只使用谱面标签，排除开发样本 `sample-001`、`sample-058`：

- 10 首恒速：3 首所有者已确认恒速（032、034、088）+ 7 首按固定 SHA-256 顺序选取；
- 5 首含至少 2 条密集短红线的变速：002、003、042、095、100；
- 5 首其他变速：025、027、040、072、091。

“密集”沿用 v547 定义：红线时长不超过 1,200 ms。完整顺序、谱面文件和分层见 `selection.json`。20 首共有 17,149 个物件，其中稳定段 16,895 个、密集段 254 个；密集段仅来自 7 首，证据量明显小于全曲结果。

## 2. 实验方法与验证口径

沿用 v547，不在本轮调阈值：

1. full / low / mid / high 四频带对数谱通量，256 采样 Hann 窗、11 采样 hop；20 首自建 full 包络与生产 `onsetEnvelope` 的逐点最大差都为 0。
2. 已知红线段内在 −30–30 ms 以 0.5 ms 步长估计相位；按“约 80% 物件有音”规则，只用段内得分最高的约 80% 物件计算鲁棒分数。
3. 比较 max / top2 两种频带聚合，以及逐段 independent / 仅短程连续的 DP 两种相位模型。
4. 报告奇偶物件交叉拟合 `actualCrossFit`，未匹配峰保留在分母中。
5. 打乱对照 `nullCrossFit` 对物件时间施加确定性的 ±15–95 ms 抖动，再走同一拟合和留出流程。
6. **主要有效性基线是 `baselineGlobalOnly`：只估计全曲统一偏移，不估计逐红线相位。** 打乱对照只用于检查方法是否完全依赖被保留的时间结构，不能替代这个基线。

四种配置在全曲都达到 20/20 首“实际优于打乱”，top2 / 短程 DP 的逐歌曲实际减打乱中位数为 **+48.98 个百分点**。这支持“物件弱标签与声学峰确有关联”，但不证明逐段精修优于全局偏移。

## 4. 密集段逐歌曲反证

下表“实际/打乱”均为 ±5 ms 内数量；基线不参与打乱。

| 样本 | 密集红线数 / 物件数 | 全局基线 | max / DP 实际/打乱 | top2 / DP 实际/打乱 | 结论 |
|---|---:|---:|---:|---:|---|
| 002 | 20 / 34 | 18 | 17/6 | 16/6 | 有真实相位信号，但低于基线 |
| 003 | 29 / 50 | 15 | 9/9 | 9/10 | 不优于基线，max DP 也不优于打乱 |
| 025 | 1 / 3 | 1 | 3/0 | 3/0 | 有改善，但仅 3 个物件 |
| 042 | 19 / 148 | 82 | 92/36 | 92/35 | 主要正例，改善 10 个 |
| 072 | 1 / 4 | 3 | 3/1 | 3/1 | 与基线相同，样本很少 |
| 095 | 4 / 14 | 4 | 2/2 | 2/2 | 低于基线，且与打乱相同 |
| 100 | 6 / 1 | 1 | 0/0 | 0/0 | 支持严重不足 |

微合计的微小正差主要由 042 拉动。去掉 042 后，top2 / DP 只剩 **33/106**，基线为 **42/106**；max / DP 为 **34/106**，基线同为 42/106。事先划出的 5 首密集变速中，去掉 042 后 top2 / DP 为 **27/99**、max / DP 为 **28/99**，基线均为 **38/99**。

这与 v547 的低支持猜想一致：002、003 平均每条密集红线只有约 1.7 个物件，奇偶折后平均每折不足 1 个；短程 DP 有时能修复独立估计，但不能稳定超过全局基线。042 的正例值得保留，不能外推到全部密集变速。

## 5. 猜想、验证与否定

### H1：v547 在 058 上的收益可以直接泛化到更多歌曲

**未支持。** 20 首相对打乱都有一致性信号，但相对全局基线的逐歌曲中位数没有提升；校准正常的 17 首微合计还下降 12 个物件。058 类型收益不能作为普遍收益的估计。

### H2：top2 多频带聚合应稳定优于 max

**未支持。** 全曲 top2 / independent 与 max / independent 只差 10 个物件；top2 / DP 与 max / DP 的全曲和密集段也互有小幅差别。没有足够证据选择一个“普遍最好”的频带聚合。

### H3：短程 DP 可以解决密集短红线

**仅支持“有时优于独立估计”，否决“已解决密集段”。** DP 在 042 有明显收益，但在 003、095、100 等样本没有；5 首选定密集变速的微合计不高于基线，逐歌曲中位数更差。

### H4：实际显著优于打乱，就足以证明精修有效

**否决，这是本轮验证设计需要特别警惕之处。** 打乱幅度为 ±15–95 ms，而相位搜索只有 ±30 ms、峰匹配只有 ±10 ms；很多打乱物件被有意推到不可恢复范围。因此实际与打乱的大差值部分由对照构造决定。它是时间结构破坏性 sanity check，不是等难度声学基线。最终判断必须看全局偏移基线、逐歌曲宏指标和逐首反例。

### H5：交叉拟合后的 ±5 ms 一致率等于真实 onset 误差

**不成立。** 拟合和评估仍共享 full onset 包络与谱面弱标签；全局偏移也由稳定段物件校准。它能衡量留出物件与声学峰的一致程度，不能区分谱面物件自身偏差、真实音头位置和谱通量峰位置，更没有测试未知红线/BPM 的发现能力。

## 6. 校准异常与保留规则

以下样本保留在主结果中，没有事后删除：

- `sample-027`：全局偏移 +60 ms，撞到搜索边界，校准物件 574；
- `sample-044`：−3.75 ms，出现不同于常见正解码延迟的负偏移，校准物件 124；
- `sample-091`：−16 ms，同样为负偏移异常，校准物件 309。

`calibrationNormal` 的 17 首是敏感性分析，不是新的“优选测试集”。后续全局校准若撞界或为负，应显式输出低置信度，不能用逐段精修掩盖。

## 7. 当前决定与下一步

1. **保留研究代码和完整阴性结果，不接入生产。** 当前没有稳定超过全局偏移基线。
2. **不再围绕同一最近峰阈值继续调参。** 这会把 254 个密集物件上的小波动变成事后选择。
3. 下一步应给 042 正例和 003/095 反例建立独立 onset 精标对照，并把段内支持数、奇偶折相位一致性、真实/基线差作为低置信度依据。先回答“声学峰是否真能定位到 5 ms”，再决定是否恢复逐音精修。
4. 全自动不变速 BPM 与变速发现仍是独立问题；本轮结果不能更新此前 100 首自动检测正确率。

# v567 / E8：DDC parabolic 候选的 E5 反折校准

## 结论

**E8 不能直接替换 E5。** 总体有音物件人口加权 ±5 ms 正确率只有 **14.7093%**，相对 E5 的 70.4738% 下降 **55.7645 个百分点**；但 sample-044 达到 **98.1280%**，说明 DDC 在候选充足且校准可靠时有明显价值。

- H1“直接 DDC 替换优于 E5”：**不成立**。
- H2“总体净修正为正且 sample-044 保持 80%”：**不成立**；sample-044 条件成立，但净修正权重为 **-1020.4778**。
- H3“结果由已验证的冻结候选和反折校准确定重建”：**成立**。
- 未修改生产 BPM 代码，未重新推理，未读取或评估六首独立确认歌曲。

## 冻结规则

只使用 v560 的 `ddcParabolicResidualMs`，绝对候选为 `targetMs + residual`。该候选来自已通过官方 fixture parity 的 DDC CHALLENGE 模型和已冻结的抛物线亚帧插值。

对每个歌曲 / 奇偶折，以另一折有音且有 DDC 候选的物件估计原始绝对误差中位数；至少 3 对，否则回退 0 ms。只允许平移已有 DDC 候选，不使用 full 回退，不改模型、难度、阈值、匹配窗口或插值。缺失 DDC 候选在有音召回和转移中均计为不正确。

## 总体结果与覆盖上限

| 指标 | E5 | E8 DDC parabolic |
|---|---:|---:|
| 有音 ±5 ms 加权正确率 | **70.4738%** | **14.7093%** |
| 全物件候选覆盖率 | 95.8593% | 34.8552% |
| 候选精确率 | 38.7936% | 22.2686% |
| clear 召回 | 68.0896% | 25.4997% |
| no_clear 候选输出率 | 96.6972% | 38.0031% |
| 配对绝对误差中位数 | 2.7159 ms | 2.1567 ms |
| 配对绝对误差 p95 | 10.1463 ms | 34.6113 ms |

90 个物件中只有 48 个有 DDC 候选；52 个有音物件中只有 31 个有候选。有音候选可用权重为 586.2778 / 1829.9778，**即使所有已有 DDC 候选都正确，直接方案的有音召回上限也只有 32.0374%**，不可能达到 80%。

no_clear 输出率较低主要反映候选稀少，不能解释为有效的无音抑制。

## 分歌曲结果

| 歌曲 | 有音 ±5 ms 正确率 | 全物件候选覆盖率 | 候选精确率 | no_clear 输出率 |
|---|---:|---:|---:|---:|
| sample-044 | **98.1280%** | 92.3822% | 95.3238% | 34.3154% |
| sample-032 | 11.5056% | 23.3983% | 28.2142% | 23.4618% |
| sample-002 | 0.0000% | 56.7417% | 0.0000% | 63.0602% |

sample-044 的 clear 召回为 99.0824%，配对绝对误差中位数 1.6656 ms、p95 3.8600 ms。它不是总体成绩，但证明神经候选在一首开发歌曲上有很高的局部质量。

| 歌曲 / 应用折 | 拟合对数 | 修正量 | 回退 |
|---|---:|---:|---|
| sample-044 odd | 11 | -0.5603 ms | 否 |
| sample-044 even | 11 | -0.2413 ms | 否 |
| sample-032 odd | 4 | +26.3169 ms | 否 |
| sample-032 even | 1 | 0.0000 ms | **是** |
| sample-002 odd | 3 | +35.2068 ms | 否 |
| sample-002 even | 1 | 0.0000 ms | **是** |

sample-032 和 sample-002 的 even 折都只有 1 个可用反折配对，按冻结规则回退 0 ms，未消除约 20–30 ms 的系统延迟。两首歌曲校准后配对误差中位数仍分别约 +25.4964 ms 和 +25.4871 ms。这是直接方案失败的重要原因，但不能事后修改本实验的回退来美化 E8。

两个 fixed 都在 sample-044，该歌曲只有一个权重 1.1 的 broken；sample-032 和 sample-002 没有 fixed。直接替换丢失了 E5 已正确的大量候选。

## 独立复验与失败记录

`check-results.py` 从 v560 和 v563 重建 90 行绝对候选、6 组反折校准、候选存在性、CSV、overall / perSample / perStratum / perFold、转移和覆盖指标，并确认 v560 结果复验及官方 parity 均通过。最终输出 `V567_RESULT_VALIDATION_PASSED`，H1=false、H2=false、H3=true。

第一次分析输出 CSV 时遗漏继承自 v563 的 `fullResidualMs` 和 `correctionMs` 两列而失败；已只补齐 CSV 字段，候选、校准规则和指标未改变。

所有成绩都来自三首开发歌曲的 90 个 provisional 视觉盲标，不是独立确认，也不能代表生产泛化能力。

## 下一步

不再评估“无回退的直接 DDC 替换”。下一次实验若要利用 DDC，必须同时解决两个结构性问题：

1. DDC 缺失时用 E5 候选保留覆盖率；
2. DDC 反折配对不足时使用已冻结的 E5 修正量，而不是 0 ms。

这应作为一个完整的、预先冻结的层级回退规则测试，不能按歌曲名称选择方法。即使改善开发集，也仍需在达到有希望的冻结方案后再使用独立确认集。

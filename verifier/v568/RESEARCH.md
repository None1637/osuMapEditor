# v568 / E9：DDC 候选与 E5 的层级回退融合

## 结论

**E9 被拒绝，保留 E5 作为当前开发基线。** E9 的有音物件人口加权 ±5 ms 正确率为 **61.9941%**，低于 E5 的 **70.4738%**，下降 **8.4798 个百分点**，未达到 80% 目标。

- H1“E9 的总体有音正确率高于 E5”：**不成立**。
- H2“E9 净修正为正、sample-044 保持至少 80%，且不增加 no_clear 输出率”：**不成立**。sample-044 达到 99.1086%，但净修正权重为 **-155.1778**，no_clear 候选输出率由 96.6972% 升至 98.3273%。
- H3“所有候选、修正来源和指标都能从冻结输入独立重建”：**成立**。
- 未修改生产 BPM 代码，未重新推理，未读取、解码或评估六首独立确认歌曲。

## 冻结规则

E9 对 90 个开发物件逐件执行同一规则，不按 sampleId 选方法：

1. 若存在 DDC raw 候选，优先使用 `targetMs + ddcParabolicResidualMs` 作为绝对候选时间。
2. DDC 候选在同曲反折校准记录至少有 3 对且 `usedFallback=false` 时，使用该 DDC 修正量。
3. DDC 校准记录使用回退时，不直接置零，而使用同曲同折已冻结的 E5 `correctionMs`。
4. 没有 DDC 候选时，完整沿用 E5 候选及误差；两者都缺失则仍计缺失。
5. 不增加官方峰、重新匹配、阈值选择或事后单曲覆盖规则。

候选相对 `targetMs` 的残差一律先恢复为绝对时间，再与标注计算误差：`candidateAbsoluteMs = targetMs + residualMs`，`errorMs = candidateAbsoluteMs - actualOnsetMs`。主指标仍是有音 clear + approximate 物件的人口加权 ±5 ms 正确率，缺候选计不正确。

## 总体结果

| 指标 | E5 | E9 层级回退 | E9 - E5 |
|---|---:|---:|---:|
| 有音 ±5 ms 加权正确率 | **70.4738%** | **61.9941%** | **-8.4798 pp** |
| 全物件候选覆盖率 | 95.8593% | 97.1684% | +1.3091 pp |
| 候选精确率 | 38.7936% | 33.6660% | -5.1276 pp |
| clear 召回 | 68.0896% | 51.3833% | -16.7063 pp |
| no_clear 候选输出率 | 96.6972% | 98.3273% | +1.6300 pp |
| 配对绝对误差中位数 | 2.7159 ms | 2.8936 ms | +0.1777 ms |
| 配对绝对误差 p95 | 10.1463 ms | 9.8353 ms | -0.3110 ms |

候选数由 83 增至 85，但正确物件数仍为 36。覆盖率上升和 p95 略降都没有转化为主指标收益，不能据此宣称方案改善。no_clear 输出率接近 98% 也再次说明当前候选生成没有可靠的无音判别能力。

## 分歌曲结果

| 歌曲 | E5 有音正确率 | E9 有音正确率 | fixed / broken |
|---|---:|---:|---:|
| sample-044 | 92.5812% | **99.1086%** | 2 / 0 |
| sample-032 | 69.3737% | **66.1556%** | 1 / 1 |
| sample-002 | 67.6119% | **32.3881%** | 0 / 2 |

sample-044 的单曲提升是真实观测，但不能代表总体：该曲人口权重只有 125，而 sample-032 和 sample-002 的权重分别为 2410 和 933。E9 在权重更大的两首歌上退化，最终净收益为负。

## 候选与修正来源

| 来源 | 物件数 |
|---|---:|
| DDC parabolic 候选 | 48 |
| E5 full 候选回退 | 42 |
| DDC 反折修正 | 36 |
| E5 修正量回退（DDC 候选存在但 DDC 校准不足） | 12 |
| E5 完整候选回退 | 42 |

E5 的整曲修正量不保证能校正 DDC 峰：full-onset 峰与 DDC 峰可能对应不同声学特征或时间基准。把二者混合后，sample-002 的配对绝对误差中位数由 3.9022 ms 恶化到 6.8182 ms；sample-032 也由 4.2487 ms 变为 4.5365 ms。相反，sample-044 的 DDC 自身反折校准较可靠，因此保留并扩大了 E8 的局部优势。

这说明“DDC 缺候选时补 E5、DDC 缺校准时借 E5 修正”解决了覆盖和零修正问题，却没有解决跨模型校准语义不一致的问题。

## 独立复验与失败记录

`check-results.py` 不调用分析脚本的聚合函数，而是从 v567 候选独立重建 90 行的候选来源、修正来源、绝对时间和误差，并复算 CSV、overall / perSample / perStratum / perFold、转移、来源计数和守卫。最终输出 `V568_RESULT_VALIDATION_PASSED`，H1=false、H2=false、H3=true。

第一次分析在写 CSV 时因继承字典包含额外字段而失败；已仅将 writer 改为 `csv.DictWriter(..., extrasaction="ignore")`。候选、融合规则、校准和误差数值均未改变。

所有成绩都来自三首开发歌曲的 90 个 provisional 视觉盲标，不是独立确认，不能据此宣称生产泛化能力。

## 下一步

不采用逐件混合 DDC 与 E5 修正量的 E9。下一轮可预注册“整曲可靠性门控”：只有整曲奇偶两折都拥有足够的 DDC 自身反折校准支持时才启用 DDC，否则整曲保持 E5。该门控必须使用不依赖当前物件标签的覆盖与校准支持特征，并重新冻结阈值和守卫；在看到结果前，它不是已验证方案。

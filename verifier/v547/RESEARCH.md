# v547：八成含音弱标签的多频带鲁棒相位实验

## 结论先行

所有者明确：**可根据谱面物件时间点判断有没有音，约 80% 的情况下都有音。** 本轮据此把物件时间作为含约 20% 离群值的弱标签，不再要求逐段人工确认有无声音。

弱标签、多频带 onset、段内鲁棒评分和短程相位连续性，在较长/稳定段显示了明确收益；但**仍未达到每个音 offset 误差低于 5 ms，001 密集短红线区甚至没有可靠优于打乱对照。**

- 058 复核段：四种配置的奇偶留出结果均为 **66–67/84（78.6–79.8%）**在 ±5 ms 内；v547 同口径全局偏移基线为 10/84。对应打乱对照为 24–25/84。
- 001 复核全部：四种配置为 **30–32/43**；复核密集区最高 9/17，但对照也可达到 9/17。
- 001 全曲密集区：四种配置为 **9–13/27**，打乱对照为 **12–13/27**，没有可靠选择性。
- 058 全曲密集区：四种配置为 **13–15/27**，打乱对照为 **6–8/27**；有弱标签一致性信号，但最高也只有 55.6%。
- 以上仍是已知红线边界和物件弱标签下的一致性，不是全自动检测正确率，也不是独立声学 onset 真值误差。

本轮没有修改生产 BPM 代码。

## 方法

1. 特征：full / low / mid / high 四个频带的对数谱通量，256 采样 Hann 窗、11 采样 hop。自建 full 包络与 v545 使用的 `onsetEnvelope` 逐点最大差为 0，排除了特征实现漂移。
2. 每个物件在候选相位下取得四频带分数，分别测试：
   - 四频带最大值；
   - 最强两个频带的均值。
3. 每条已知红线段在 −30–30 ms 内以 0.5 ms 步长估计唯一相位。
4. 按所有者约 80% 含音规则，只保留段内得分最高的约 80% 物件计算鲁棒分数，允许其余物件为离群值。
5. 两种相位模型：
   - 每条红线独立估计；
   - DP 在相邻短红线间传递相位，惩罚为 0.0005×相位差²。
6. v1 曾对所有相邻红线施加连续性，导致跨长段错误传播；v2 改为**只有相邻两段都不超过 1.2 秒才施加惩罚，跨长段自由重置**。
7. 验证：
   - 全量拟合仅作描述；
   - 奇数索引物件拟合、偶数物件评估，再交换，报告 `actualCrossFit`；
   - 物件时间打乱后走完全相同的拟合与留出流程，报告 `nullCrossFit`；
   - 评估使用 full 频带、20 ms 峰抑制、±10 ms 最近峰；未匹配保留在分母内。

全局解码偏移沿用 v545，在密集区和人工复核段之外校准。因此复核段没有参与全局偏移拟合；但全曲稳定区的交叉验证仍可能共享这一全局参数，不能视为完全独立测试。

## 猜想与验证

### H1：把物件视为 100% 精确 onset，是此前最近峰不稳定的重要原因

**部分支持。** 改为允许约 20% 离群值并引入多频带一致性后，058 复核段从同口径基线 10/84 提升到 66–67/84，且明显优于打乱对照。这说明 058 的 −12.653 ms 中位残差确实包含局部相位问题，而不是所有音符都没有可定位音头。

但 001 密集区没有同样提升，不能把“80% 有音”误解成“80% 都能以 5 ms 精确定位”。

### H2：多频带可解决被其他乐器遮蔽的 onset

**058 支持，001 密集区未支持。** top2 与 max 都保留在结果中，没有事后只挑最好配置。001 的密集红线多数每段只有 2 个物件，奇偶折后每折只剩约 1 个物件；多频带无法替代不足的段内支持。

### H3：相位连续性可以帮助密集短段

**仅在短程、有限程度上支持。** DP 修复了部分段，但 001 密集区真实与打乱仍接近。奇偶折所得相位差 ≤5 ms 的红线比例也只有约 55.6%（001 max DP），说明折间稳定性不足。

### H4：所有红线之间都应传递相位

**否决。** v1 全局 DP 在 058 全曲只剩约 33.1%，因为长段之间也被强制平滑。v2 长段自由重置后，058 max DP 全曲恢复至 56.2%，001 max DP 为 79.8%。v1 结果保留在 `consensus-results-global-dp-v1.json`。

### H5：留出一致性已经超过 5 ms 独立声学精度要求

**不成立。** 当前评估仍以物件时间为弱参考，最近峰残差 ≤5 ms 只是弱标签一致性。它不能区分谱面物件自身的毫秒偏差与声学 onset 偏差；也没有解决未知红线边界、未知 BPM 的全自动问题。

## 当前可行边界

- **可保留方向：** 物件弱标签 + 多频带 + 鲁棒段相位 + 仅短程连续性。它对 058 类型段落明显有效。
- **不可宣称：** 每个音 5 ms、001 类型密集变速已解决、全自动红线发现已解决。
- **低置信度必须显式保留：** 段内物件少、奇偶折相位不一致、真实与打乱优势不足时，不能输出看似精确的 offset。
- 下一步若要提高泛化，应在更多样本上验证该精修器，并将“相位一致性”和“独立声学精度”分别报告；001 密集段需要额外信息或人工精标，不宜继续只调最近峰阈值。

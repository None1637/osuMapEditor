# v565 / E6：同曲 leave-one-out 中位数校准

## 结论

**E6 被拒绝，保留 E5 作为当前更好的开发集方案。** E6 的有音物件人口加权 ±5 ms 正确率为 **64.0257%**，比 E5 的 70.4738% 低 **6.4482 个百分点**，未达到 80%。

- H1“E6 优于 E5”：**不成立**。
- H2“净修正为正且 sample-044 保持 80%”：**不成立**；sample-044 保持在 92.5812%，但净修正权重为 **-118.0000**。
- H3“每个物件排除自身标签且结果可独立重建”：**成立**。
- 未修改生产 BPM 代码，未读取或评估六首独立确认歌曲。

## 冻结规则

对每个输出物件，使用同曲其他所有 clear / approximate 且已有 full 候选的物件，取原始签名绝对误差的未加权中位数；当前 segmentId 永远排除。少于 3 对回退 0 ms。只平移已有候选，不按奇偶折或红线分组，不重新选峰，不搜索阈值或其他变体。

```text
e6CandidateAbsoluteMs = fullCandidateAbsoluteMs - leaveOneOutCorrectionMs
e6ErrorMs = fullErrorMs - leaveOneOutCorrectionMs
```

主要比较基线是 E5；主指标仍是 clear + approximate 的人口加权 ±5 ms 正确率，缺失候选计为不正确。

## 总体与分歌曲结果

| 范围 | full | E5 反折中位数 | E6 leave-one-out |
|---|---:|---:|---:|
| 全部有音物件，加权 | 5.7299% | **70.4738%** | **64.0257%** |
| sample-044 | 93.4727% | **92.5812%** | **92.5812%** |
| sample-032 | 0.0000% | **69.3737%** | **69.3737%** |
| sample-002 | 0.0000% | **67.6119%** | **32.3881%** |

E6 的正确物件数为 34，E5 为 36。sample-032 虽然 broad 正确率不变，但 clear 召回从 56.8082% 提升到 79.3980%；sample-002 的明显下降使总体净结果为负。

### 误差中心改善不等于 ±5 ms 正确率改善

| 指标 | E5 | E6 | E6 − E5 |
|---|---:|---:|---:|
| clear 召回 | 68.0896% | 72.0137% | +3.9241 pp |
| 候选精确率 | 38.7936% | 35.2441% | -3.5495 pp |
| 配对签名误差中位数 | -0.1915 ms | -0.0578 ms | +0.1336 ms |
| 配对绝对误差中位数 | 2.7159 ms | 2.1432 ms | -0.5727 ms |
| 配对绝对误差 p95 | 10.1463 ms | 10.0272 ms | -0.1190 ms |
| **有音 ±5 ms 加权正确率** | **70.4738%** | **64.0257%** | **-6.4482 pp** |

因此不能仅凭中位数或 p95 判断方案更好。E6 让部分误差分布更集中，却把高权重的 approximate 物件推过 5 ms 边界；这与主指标下降并不矛盾。

## 对 v564 猜想的反馈

v564 正确识别了 E5 奇偶折中位数完全反对称的代数来源，但“取消折限制会提高主指标”的推测没有成立。E5 的两个不同修正在当前三首开发歌曲的阈值指标上更有利，不过这仍不证明奇偶折对应真实音频延迟。

E6 的分折正确率进一步分化为 odd 35.0016%、even 85.3901%，说明只消除修正量的折间差异并不能保证各折物件都落在 5 ms 内。下一轮不应继续搜索全曲中位数的折、权重或收缩变体，而应回到 E5，研究局部声学 onset 精修及红线段残差。

## 独立复验

`check-results.py` 从 v563 候选重新构建 90 个 leave-one-out 修正，逐件确认自身 segmentId 不在拟合集、拟合物件同曲且满足标签和候选资格，并独立复算候选绝对时间、CSV、overall / perSample / perStratum / perFold、两组转移和输出守卫。

复验结果：H1 = false、H2 = false、H3 = true，80% 目标标志为 false，sample-044 保持标志为 true。最终标记为 `V565_RESULT_VALIDATION_PASSED`。

## 限制

这是三首开发歌曲、90 个 provisional 视觉盲标上的 leave-one-out 结果，不是独立确认。留一法只排除当前物件，其他同曲标签仍参与修正，因此不能把 64.0257% 当作生产泛化成绩。校准仍未增加候选，no_clear 输出率保持 96.6972%，缺失和误报问题均未解决。

# 用户需求整理（soulten，Discord 反馈）

来源：soulten 在 Discord 的实测反馈（2026-09 凌晨消息 + 截图）。按用户最终给出的优先级分类整理，每条附原始上下文以便溯源。

## 一、機制類（优先处理）

1. **增加數值的控制方法**（适用于所有窗口里的数值输入框）
   - 原话：「這個介面沒有滑條有點雷霍，或著可以做成 adobe 那樣按住數字就可以靠滑鼠水平方向移動改變數值，會比放一個小滑條好調」
   - 期望：所有对话框（旋转/批量复制/对称滑条/多边形生成等）的数值输入框支持按住数字左右拖动调值（Adobe 式 scrubber），替代小滑条。

2. **滑條錨點尾的顯示跟 stable 不一樣**
   - 原话：「anchor 的力學跟 stable 不一樣」（附与 stable 的对比截图）
   - 用户澄清：指**同一个滑条在本编辑器与 stable 中渲染出的形状有差异**（stable 与 lazer 的滑条形状应完全相同），属于滑条路径生成的保真度问题。

3. **游標在滑條上的時候顯示其滑條點**
   - 原话：「滑上去時想要跟 stable 一樣會預覽滑條的點」
   - 即 hover 滑条时预览其控制点（stable 行为），目前需选中才能看到。

4. **時間軸對顯示與效能的關係**
   - 原话：「暫停後撥放的瞬間會突然顯示更早時間軸的畫面，而且更改時間軸後幾秒幀數會比較低」
   - 两个现象：① 暂停→播放瞬间闪回更早位置的画面；② 拖动/更改时间轴后数秒内帧数偏低。

5. **撥放時滾輪控制時間軸的手感問題**
   - 原话：「播放時滾輪移動時間軸的判定跟 stable 不太一樣，然後滾輪輸入有機會不響應」
   - 含滚轮输入偶发无响应。

6. **右上角物件詳細資訊無法顯示滑條點的資訊**
   - 原话：「右上角的詳細資訊不會顯示滑條點的資訊」
   - 现状：只显示 x/y 坐标与 Prev/Next 间距（如 `0.86x(223px)`），选中滑条控制点时无对应信息。

## 二、顯示類

1. **滑條點會無法顯示**
   - 原话：「不是我滑條點呢」（截图：框选区域内滑条的控制点未显示）

2. **增加黃框開關**
   - 原话：「麻煩增加一個開啟關閉黃框的選項」（选中物件的黄色包围框）

3. **上下時間軸 UI 半透明**
   - 原话：「上下兩條時間軸想要半透明的」

4. **左下角的資訊在播放時不會改變**
   - 原话：「左下角的時間在播放時不會改變 應該是 bug…」（截图：播放中左下角时间停留在 3:55.977）

5. **stable 選中框和 stable 版不一樣**
   - 原话：「這框框對嗎」（截图对比：本编辑器的 stable 选中框与 stable 客户端的选中框样式不一致）

6. **視窗條隱藏**
   - 原话：「再許個願 視窗條可以隱藏」（窗口标题栏可隐藏/无边框模式）

## 三、沒這麼重要的

1. **fps 顯示開關**（右下角帧数显示做成可开关）
2. **stable 滑條點有點肥**（原话：「然後點還是有點肥」——stable 风格控制点尺寸需再调小）
3. **快捷鍵單獨開一個頁面出來顯示&更改**（快捷键列表页 + 自定义改键）
4. **播放時看波形圖會糊成一坨**（用户自注：大概率是显示器该换 OLED 了——可先观察是否为渲染问题）
5. **右下角的播放按鈕怎麼特別紅…**（播放按钮配色疑问）

## 附：未列入清单的零散反馈（待确认）

# 实现难度评估与优先级（2026-09-10 整理，基于代码现状核实）

## 难度估计依据（关键代码触点）

- 数值输入框：已有封装组件 `DraftNum`（`DraggableDialog.tsx:91`），7 个对话框共 45 处使用，另有 ~15 处裸 input。改 `DraftNum` 加按住拖动即可覆盖大部分窗口。
- 滑条路径：`src/osu/sliderPath.ts` 是"对齐 lazer 的自主实现"，**已记录与 stable 的已知分歧**：v148 末端切线延长（stable 在末两点重合时不延长）、v39 catmull 端点约定。正对应用户说的"锚点尾"差异。
- 左下角时间：`Timelines.tsx:1088` 只用 `useEditor()` 订阅，播放逐帧走独立的 `playbackFrameVersion` 通道不触发它 → 播放中不刷新。`TimingPanel.tsx:15` 已有现成的 `usePlaybackFrame()` 解法。
- 时间轴半透明：上下时间轴背景已是 0.7~0.72 alpha（`Timelines.tsx:370/993/1071/1086/1133`），加开关或调值即可。
- 黄框：`EditorCanvas.tsx:729`（`#f2b544`）；FPS 显示：`FpsCounter.tsx`，`App.tsx:754` 无条件挂载无开关；播放按钮：`Timelines.tsx:1114` `bg-pink-500`。
- 播放闪回：`play()` 锚定在 +20ms 未来时刻且渲染位置再减 outputLatency（~42ms），恢复播放后最初几帧渲染位置比暂停点早 ~20-60ms = 可见回跳。
- 滚轮：`wheelSteps`（`seekSnapping.ts:70`）凑满 120px 才出一步，触摸板小增量/反向折返时表现为"不响应"。
- 窗口条：Electron `BrowserWindow`（`electron/main.cjs:151`）未设 `frame/titleBarStyle`，隐藏后需自绘拖拽区与窗口控制按钮。
- 皮肤切换残留：`store.applySkinSamples` 只覆盖新皮肤存在的 stem，旧皮肤独有的采样残留继续生效；选中装饰层缓存按 Skin 对象身份做键而皮肤是原位修改的单例，换肤后可能沿用旧贴图。

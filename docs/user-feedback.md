## 明细

### F07（P0，最严重）超长滑条冻结 + 恢复后失色
- 现象：拉一条很长的滑条 → 画面冻结成白屏（截图：游玩区全白，UI 仍在）；
  恢复后所有物件失去颜色（只剩白描边）。
- 初步猜测：超长滑条导致路径采样/ tessellation 爆炸（O(n²) 或巨额点数）卡死渲染；
  白屏+失色疑似 WebGL/canvas 上下文丢失或静态缓存贴图被清空后未重建。
- 排查入口：renderer.ts 滑条绘制与 v245-v248 的合批缓存（cacheKey/静态层）；
  先本地复现（拖一条贯穿全屏的长滑条），profile 卡在哪一步。

### F05 旋转/缩放窗口
- a) 希望改数值时游玩区实时预览（现在是点「应用倍率」/顺逆时针按钮才生效）。
- b) bug：用户报告「不能应用旋转」（角度输入 67 后点按钮无效果？）——需先复现确认。

### F04 / F09 游玩区限制逻辑两处不一致

- F09：包围框整体拖动时，只要组内任一滑条锚点出界就整组禁止拖动——应允许拖动
  （或只钳制越界量，stable 行为待确认）。

### F02 选中滑条后锚点/连线被矩形区域裁剪（2026-09-28 已确认）
- 原话：「游标放上去看可以看到所有点 但是选中后就不能」。
- 确认含义：选中滑条后，锚点与锚点间连线在某个矩形区域外被裁剪为不可见——
  疑似游玩区平移/缩放（v223 playfieldPan）后裁剪矩形没跟着变换。
- 排查入口：renderer.ts 锚点/控制点连线绘制层与 v245-v248 合批缓存的层裁剪
  （clip rect 用游玩区原始矩形，未乘 playfieldTransform）。
- 优先级 P1，预估 1–2h。

### F03 stable 选中效果（2026-09-28 已确认，用户提供了 stable 对比截图）
- stable 实际表现：
  - 圆圈物件选中 = **黄色/橙色圆形描边环**（hover 另有蓝色圆环）；
    当前编辑器是浅蓝圆角方框（v232 hitcircleselect），与 stable 不符。
  - 滑条选中 = **sliderborder 边框高亮描边**（截图三：蓝/橙描边），
    未选中时边框不高亮（截图四）；当前编辑器选中滑条只画方框，无边框高亮。
- 实现方向：renderer 选中态改为 stable 风格 —— 圆圈类画黄色圆环（hover 蓝色圆环），
  滑条选中时给 sliderborder 画高亮描边；hitcircleselect 方框逻辑保留或随设置切换待定。
- 优先级 P2，预估 2–3h。

### F10 框选选框配色（2026-09-28 已确认）
- 原话：「选框应该实时改变 如果点alt就变成橙黄色的逻辑 放开回复」。
- 确认含义（纯视觉）：普通框选 = 蓝色虚线 + 半透明蓝色填充；按住 Alt 框选时
  蓝色改为橙黄色（虚线+填充同步），松开 Alt 立即恢复蓝色——拖动途中按/放 Alt
  也要实时切换。选区逻辑本身不变（仅配色）。
- 优先级 P3，预估 0.5–1h。
